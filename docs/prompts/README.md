# Claude chat prompt templates

One template per content kind. Paste a template into Claude chat, fill in the
`{…}` parts, and save the JSON reply as a `.json` file to import at
**Admin → Import**. Then check every draft in the review queue before moving it
to live. AI-written Japanese can be unnatural or wrong: check against JMdict,
Tatoeba and a trusted grammar reference.

- [items.md](items.md): vocabulary, kanji, grammar point items
- [lessons.md](lessons.md): situation-based lesson units
- [sentence-patterns.md](sentence-patterns.md): sentence builder patterns
- [questions.md](questions.md): JLPT-format questions

The format reference all of them rely on is [../import-format.md](../import-format.md).
